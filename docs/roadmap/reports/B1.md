# B1 - vocabulary, feature-v1 and streaming dataset

Generated the byte-stable, SHA-256-pinned b8f23c99 vocabulary, including cosmetic
formes and Recharge. PAD/UNKNOWN/ABSENT are distinct. `FEATURE_V1.md` specifies
every dtype, shape, source and normalization: 12 oriented Pokemon tokens, one
field token and variable legal-action tokens with canonical indices and switch
pointers. The pure NumPy featurizer reads only the owner's v2 view/request;
never K, history or labels. Numeric state masks preserve unknown/absent/zero.

Missing v2 opponent item identity/absence, moves, ability and Tera identity stay
unknown (Stellar prevents inferring Tera from defensive types). Active PP is
not attached to unmatched/transformed base moves. Synthetic PP and normalized
locked disabled omissions stay unknown. Explicit weather `none`, removed own
items and Double Shock's removed `???` type slot are known absent. No simulator
knowledge semantics changed.

The R1 builder streams frames through a Python worker with backpressure,
strips K, caps debug samples at 50 frames, and commits atomic per-battle NPZ
checkpoints before fsynced journal outcomes. Only completely reproduced battles
enter ~10k-example split shards. It stores policy index, owner outcome, ending,
rating plus known bit, and battle/step/owner join keys. Exact failure reasons,
pinned resume definitions, suspension interruption and two-attempt replay
limits preserve progress. Adjacent live-view changes add example counts and
`-Once`, without presenting unmeasured K as zero. Datasets are git-ignored.

Validation: **17 focused tests pass** (15 feature, 2 builder): three exact-array
goldens, masks/pointers, determinism, absence/zero/synthetic/copy/lock/Stellar
controls, actual Knock Off, transactional rollback and torn-tail resume. W9L's
born hidden-bench cases give byte-identical feature tensors before reveal and
differ afterward, for both owners. Final idle fast gate after stopping the
build: **126.02 s** / 175 s (previous final-mask gate 143.03 s).
Node 478 pass/21 skip (+ producer
3/1); Python 282 pass, 5,484 subtests. No coverage or deadline was weakened.

Measured pilot (`424b3c9`, same exporter/layout before final missing-field mask
clarifications): **50/50 successful**, **2,646 unique examples**, **0 restarts**,
**534.83 s**. Shards, split membership, legal labels and unique join keys were
verified. Same three-worker configuration extrapolates to **8.91 h** for 3,000
battles. The first discovery pilot's 13 clear-marker failures remain preserved
under `b1-s3000-pilot/`; the successful pilot is `b1-s3000-pilot-v2/`.

Owner decision: **B1 is code only; Track B is paused until Track A (W10) is
complete.** The already-started 3,000-battle build was stopped, including its
supervisor, worker, Python process and keep-awake helper. Its completion monitor
is paused. The journal retains 35 unique completed outcomes with a complete
final line in `data/datasets/b1-s3000/`; these partial artifacts are not a
completed dataset. No build will be launched or resumed under this slice.
The committed manifest retains the sample/vocabulary and proposed 2700/150/150
split hashes; full dataset counts and failures remain unmeasured.

No full suite, download, training or push. B2 auxiliary joins on one-sided
boundaries need target-only columns if required. Unrelated concurrent TRACK-B
edits and pre-existing `scripts/package-lock.json` are excluded.
