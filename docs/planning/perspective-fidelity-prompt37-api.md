# Prompt37 private prepared-validation API

Both implementations expose three fixed-profile stages in the new `prepared_protocol_contract` module. TS names are `validatePreparedProtocolStructure`, `checkPreparedProtocolRecords`, and `validatePreparedProtocolAsset`; Python names are the corresponding snake_case names. The only profiles are `native11` and `replay-compat-v1`. Inspection accepts plain finite JSON, validates an independent snapshot, and returns recursively immutable data. It cannot install a context, change active rules, or grant engine, original-owner, K-source, reader or publication authority.

Structure validation checks the original container before projection: exact keys/schema/profile/provenance, false adoption/authority, exact claim fields, simulator identity, nested reviewed rule templates, token partition, unsupported metadata, fixture/control coverage and references. The explicit projection only converts verified simulator/Natural Cure/framing differences and finite unsupported-kind encoding into the unchanged historical full validator's vocabulary. It does not omit caller data or replace fixture/control records. Every fixture and positive is then parsed through the fixed selected grammar; each negative must fail for its declared class.

Owned context consumption runs a private per-profile `unvalidated → checking → validated` state machine. Failure is sticky. Original structure validation completes before the checking window. That window permits only the exact frozen code-pinned asset and its exact owned context, for synchronous self-record checks. A copied object, other profile or public arbitrary inspection cannot borrow it. Python holds an RLock around state transitions and binds the checking window to its owner thread; another thread fails closed. This is validation bootstrap, not native adoption or a mutable profile switch. Public loaders perform both pin and full validation.

Historical contexts and full historical validator bodies are unchanged. Native11 remains unadopted and unavailable to native producers/readers. Replay remains an explicit importer-only context without portable publication. Natural Cure remains historical from-tag only, native candidate ordered from-tag then silent, and replay exactly the two forms. Raw records and indices retain silent. Existing semantic quarantines remain stops.

The prepared assets have 101 native and 108 replay raw-only fixtures. Each links to an identical positive control and carries conservative PRE evidence. Native effect/lifecycle families remain excluded; tagless heal, cant and Court Change families remain quarantined. No fixture claims emitter execution, generated reachability, semantic closure or completeness.
