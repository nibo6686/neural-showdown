The test model uses selected literal events and independently held fixture bindings.
Synthetic protocol controls are bounded grammar/appearance examples, not proofs of
engine-reachable generated teams, full turns or profile completeness. Pinned emitter
rules justify the identities/reset distinctions; no hidden simulation was loaded.
For safety it does not retrospectively relabel executions that precede a request
binding's causal availability. It is intentionally partial: no raw request parser,
legal-action generator, complete writer inventory, public roster certificate,
profile verdict, ID join checker or general restore implementation. Unsupported
origins and missing providers cannot be promoted by passing these examples.

Unresolved decisions for lead:

2. Select and review the actual causal carrier provider: original addressed delivery
   plus unique fresh owner request, or separately proved public crosswalk. Request
   positions/names alone are insufficient. Real fixture joins remain unproved today.
3. Decide whether/how to expose retained ambiguous history to consumers under the
   frozen fact subjects/value union. If schema extension is necessary, reopen it
   explicitly; no runtime field adoption in Prompt20.
4. Review finite called/copy/acquisition writers (including currently unsupported
   Mimic) before original-possession certificates or current-slot claims. Sketch
   grammar admission is not semantic completeness.
5. Adjudicate source scope: OU preview/rules offer stronger prospective identity
   evidence, but OU is diagnostic and not silently promoted into the supported profile.

All existing fixture true-on-reentry assertions and broader historical failures are
preserved. The proposed first receipt-retention scope must not claim those active
carrier obligations solved before their independent identity evidence is admitted.
