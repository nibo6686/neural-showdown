# Prompt23 private original-owner API and lifetime

Local candidate for lead review; no registry, knowledge, delivery, publication or completeness adoption.

`PipelineIntegrationSession.getOriginalOwnerHolding(owner)` returns an opaque frozen process-local reference. `readOriginalOwnerHolding(handle, owner, packed?)` checks that exact session's addressed reference and optional exact packed-string association, then returns recursively frozen private evidence. Public labels cannot mint or transport authority. Privileged session access is outside all result/view/snapshot/bundle APIs. Holding or copying a diagnostic row does not grant a handle. An owner row contains no other-owner manager, seed, or audit capability.

Evidence keys: owner; labels {battle_id, format, simulator_revision}; raw_team; packed_team; creation_sequence:0; creation_cursor:0; field_presence; non_submitted_fields. The raw array preserves original order, move order, own keys, own undefined, non-enumerable data, nested fields, zeros and empty values. Retention and packing use separate detached copies. No JSON/unpack/default/normalization/stat calculation is used. Raw values must be primitive values or plain/null-prototype data objects/arrays; functions, accessors and non-data object prototypes fail closed rather than being silently dropped. The genuine pinned generator produces supported plain data.

The reviewed packer inventory is name, species, item, ability, moves, nature, evs, gender, ivs, shiny, level, happiness, hpType, pokeball, gigantamax, dynamaxLevel, teraType. Each top-level field is recorded as present, undefined or omitted. Nested presence survives in raw_team. role is classified only as private non-submitted generator metadata. Other own keys remain in raw_team and are classified unsupported for future adoption. No category grants original fact/wire eligibility.

Internal `OriginalOwnerCreation` is a trusted producer controller, held in ECMAScript-private session/env fields. bind/begin are exact-reference and one-shot; capture runs immediately after each actual Teams.generate and before packing a separate copy; associate records the precise string used by that owner's player payload. Both evidence rows must exist before staged diagnostics are available or payload is written. `LocalBattleEnv.inspectStagedOriginalOwner(owner)` is privileged diagnostic-only pre-write access: it yields no authorizing reference.

State transitions: new -> capturing -> staged -> active -> invalid. Session activation occurs immediately after successful settling, snapshot and initial boundary construction. Any generation/packing/submission/settling/boundary failure revokes all staged holdings. Close revokes synchronously before async cleanup. Environment retirement is an active no-op for authority; originals remain session-held through accepted and rejected candidates. Snapshot restores/candidates gain no original, current-carrier or request-delivery authority.

Legacy compatibility: only the exact bound environment in new may abandon enrollment for the existing unstarted serialized-restore path. It clears all retained state and enters terminal restored_without_originals. Boundary success returns the legacy session with no holdings, never authority. activate returns false only in that explicit state; partial native staging, invalid, active or unstarted states cannot bypass staging. Native capture/staging/active/invalid restore attempts reject. Standalone environments retain their old reset/restore behavior and no session-original authority. No new restore/fork API is introduced.

Errors are ordinary Error with original-owner/v1/ prefix: invalid-owner, unsupported-raw-value/object/accessor, duplicate-enrollment, duplicate-or-foreign-creation, invalid-capture, invalid-team, invalid-association, invalid-packed-team, not-staged, creation-restore-forbidden, inactive, foreign-or-forged-holding, packed-association-mismatch, no-creation. All owner handles become unusable after close/failure; previously obtained frozen diagnostics remain data only. Cleanup failure does not retain authority and preserves existing cleanup error behavior.

The trust boundary is reference possession within trusted production code, not a security sandbox against arbitrary in-process monkeypatching. Test-created controllers cannot impersonate a real session's private controller. SourceRegistryBuilder remains original_provider:not_adopted. Sequence/cursor zero is creation provenance only; no delivery ledger, identity crosswalk, carrier, Python bridge or future/opponent evidence is implied.
