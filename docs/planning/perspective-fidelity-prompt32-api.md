# Prompt32 immutable contexts and owned runtime API

Candidate on the installed 0.11.10 engine. Native11 is unadopted. Decoder context grants neither engine/source authority nor target fidelity eligibility.

`HISTORICAL10_CONTEXT` is one fixed, deeply frozen TS object / Python NamedTuple of recursively MappingProxy/tuple-frozen values. Shape: `{profile, protocol, inventory, effects, lifecycle}`. It captures existing historical JSON assets independently of compatibility singleton exports. `readerContext(context=HISTORICAL10_CONTEXT)` / `reader_context` accepts the exact supported context, rejects copies/foreign objects as unsupported-context, and rejects the reserved target as native11-unadopted. No caller asset injection, registry or global switching exists. `assertReaderInput(value, context)` / `assert_reader_input` retains Prompt31's schema-specific recognized-revision preflight.

Version-sensitive TS functions gain an additive trailing `rulesContext`; Python gains keyword-only `reader_rules`. Existing defaults are historical. The public TS evidence function places context after its existing internal depth argument; Python evidence preserves existing `_depth`, `_records` and `_compact` parameters. Historical wrappers bind historical context explicitly and do not accept a context selector. Recursive evidence/closure/predecessor and result/sweep/bundle calls carry the same reference. Python CLI retains Prompt31 selection and its invalid-publication exit2/empty stdout; no new CLI option is added.

`installedNativeProfile()` initializes producer metadata internally from the actual resolved/real installed package entry/root and package.json, project declaration, root lock and installed hidden lock. Exact old versions and the accepted old npm SRI must agree. It returns frozen `{reader, package_version, package_root, entry, integrity}`, owned by a private WeakSet. `assertNativeRuntimeProfile` rejects structurally identical copied descriptors. This is trusted in-process ownership, not authentication against malicious module/FS monkeypatching. Matching lock SRI describes the pinned tarball; it does not independently reattest unpacked file bytes.

Manager/session owns the runtime descriptor; environment accepts only owned descriptors, including its default internally checked construction. ManagedPlayer verifies env/tracker context equality; extractor retains that immutable context. Server initializes its manager with internally acquired ownership, with no RPC/client selector. Session and env `getReaderContext()` expose fixed decoder metadata only, never native sets, original evidence, seeds or private crosswalks. Episode producers acquire context from internal initialization/held sessions rather than caller selection. Original-owner revision is derived from that held context; existing transition identity algorithms and snapshot wire stay unchanged.

`runtimeData(context)` snapshots checked old native species/move/type/alias data into private frozen dictionaries, with frozen results/default misses and immutable lookup closures. No mutable Dex handle is retained by these producer helpers. Historical ability validation uses manifest flags rather than current Dex. Cached native lookups belong to the current process; installation changes require a fresh process and subsequent lead-approved activation work.

Lifetime: immutable reader assets live for the process and carry no revocable private authority. Producer descriptor lifetime is its owning manager/session/environment lifetime; no mutable profile swap exists. Existing B1/B2, request trace/delivery access, synchronous commit/rollback/revocation and privacy rules are unchanged.

Errors added: reader-profile/v1/{missing-historical-assets,historical-asset-mismatch,duplicate-effect,unsupported-context,installed-runtime-mismatch,unowned-runtime-profile,producer-context-mismatch}. Python context failures remain ValueError-compatible. Prompt31 revision/selection errors are retained.
